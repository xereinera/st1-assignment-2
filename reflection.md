# Did AI Make Assumptions?

It was apparent that AI assumed users would provide correct input 
and therefore did not account for common data entry errors. While 
the program was able to create a functional application that allowed 
for the entry of new data, it failed to include any error-handling functionality.
This served as a reminder that, regardless of how complete or accurate 
AI-generated work may appear, there will always be opportunities for improvement. 
In this case, the omission of error handling highlighted the importance of 
carefully reviewing AI-generated code rather than assuming it is perfect.

data was stored and displayed, as well as how effectively the program 
handled incorrect or missing information. The verification process was 
relatively straightforward because I only needed to perform a small number

# What Engineering Work Remained for You?

Aside from the additional tasks required for the overall system, the 
appointment booking component still needs error handling to prevent missing 
or incorrect data entry. It also needs a mechanism for handling duplicate appointment bookings.
